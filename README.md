# CipherGuard AI

AI-Powered Static Malware Threat Assessment & Secure File Storage.

## Repository Structure

```
cipherguard-ai/
  backend/       # Node.js / Express / TypeScript backend (Members 2 & 3)
  frontend/      # React / Vite / Tailwind frontend (Member 4)
  ml-service/    # Python / FastAPI / EMBER static ML model (Member 1)
```

## Parallel Workstreams
- **Member 1**: AI/ML Module (FastAPI, EMBER dataset, Random Forest)
- **Member 2**: Backend API, Database & Authentication (Express, Prisma, PostgreSQL, JWT)
- **Member 3**: Cryptography & Secure Storage (AES-256-GCM, RSA-OAEP, SHA-256 verification, secure storage)
- **Member 4**: Frontend, UI/UX, Testing & Deployment (React, Vite, Tailwind CSS)
